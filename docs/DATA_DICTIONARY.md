# Data dictionary: `bond_month_panel`

One row per corporate bond per month-end. Same columns in the group database table `ml2.bond_month_panel`
and in `data/processed/bond_month_panel.parquet`.
Generated by `scripts/write_data_dictionary.py` from `src/ml2/schema.py`; edit there, not here.

## Sources

| Source | What it gives |
|---|---|
| TRACE Enhanced (FINRA's corporate bond trade reports, via WRDS), cleaned | Each bond's yield, price and volume on each trading day |
| TRACE corporate bond master file | Issuer, stock ticker, coupon, maturity, 144A flag, grade, debt type |
| US Treasury par yield curve (treasury.gov) | The benchmark the spread is measured against |
| FRED (ICE BofA spread indices, VIX) and the New York Fed (SOFR) | Market backdrop |
| Daily stock prices, shares outstanding, quarterly balance sheets, GICS sectors | The issuer's equity features, always as known on the snapshot date |

## Rows kept

Straight corporate bonds with a fixed coupon, not convertible, issued by a company with a listed stock,
traded on the month-end day, 1 to 30.5 years to maturity, yield between 0% and 40%, spread between -100 and 3,000 bp.

## Columns

Some columns contain the target or future information and must never be model inputs (list at the end).
`ml2.schema.feature_columns()` returns the allowed inputs.


### Identifiers

| Column | Description |
|---|---|
| `snapshot_date` | Month-end snapshot: the last bond trading day of the month |
| `cusip_id` | 9-character CUSIP: the bond's unique identifier |
| `issuer_ticker` | Stock ticker of the company that issued the bond; grouping key for issuer-grouped validation |
| `issuer_name` | Issuer name |
| `partition` | train / gap / valid / test by snapshot date (see config.yaml split) |

### Target (regression, main report)

| Column | Description |
|---|---|
| `spread_bps` | TARGET. Bond yield minus the Treasury yield of the same maturity, in basis points (1 bp = 0.01%) |
| `yield_pct` | The bond's yield on the snapshot day (volume-weighted over trades), percent. Contains the target: not a feature |
| `ust_yield_at_maturity_pct` | Treasury yield at the bond's remaining maturity, percent. Contains the target: not a feature |

### Annex target (classification, Naive Bayes)

| Column | Description |
|---|---|
| `spread_change_next_bps` | Spread at the next month-end minus spread now (empty if the bond does not trade then). Future info: not a feature |
| `widens_25bp` | ANNEX TARGET. 1 if the spread widens by 25 bp or more by the next month-end, 0 if not, empty if unknown |

### Bond terms

| Column | Description |
|---|---|
| `years_to_maturity` | Years until the bond repays its principal |
| `maturity_bucket` | Maturity bucket: 1-3y, 3-5y, 5-7y, 7-10y, 10-20y, 20y+ |
| `coupon_pct` | Annual interest the bond pays, percent of face value |
| `bond_age_years` | Approximate years since the bond was issued |
| `grade` | Credit grade flag: I = investment grade, H = high yield (latest flag, not as of the snapshot) |
| `grade_bucket` | IG or HY: the two strata for metrics and the quality gate |
| `is_144a` | True for a privately placed bond (Rule 144A), usually less liquid |
| `debt_type` | Debt type code (seniority and structure, e.g. S-NT senior note) |
| `is_subordinated` | True if the bond is subordinated (paid after senior debt in a default) |

### Liquidity

| Column | Description |
|---|---|
| `n_trades` | Number of trades on the snapshot day |
| `log_par_volume` | log(1 + face value traded on the snapshot day, USD) |
| `has_inst_trade` | True if at least one trade of $1 million face value or more that day (an institutional trade) |
| `price` | Price in percent of face value (institutional trades if any, else all trades). Contains the target: not a feature |
| `trade_days_in_month` | Number of days in the month the bond traded |
| `log_par_volume_month` | log(1 + face value traded over the month, USD) |

### Issuer structure and sector

| Column | Description |
|---|---|
| `n_bonds_issuer` | Number of the issuer's bonds in this snapshot |
| `issuer_log_par_volume_month` | log(1 + face value traded over the month across all the issuer's bonds) |
| `sector` | GICS sector of the issuer, as of the snapshot where available |
| `sector_is_pit` | True if the sector is as of the snapshot date, False if it is today's sector |

### Issuer's stock and balance sheet (as of the snapshot date)

| Column | Description |
|---|---|
| `vol_20d` | Issuer's stock: annualized volatility of daily returns over 20 trading days |
| `vol_60d` | Issuer's stock: annualized volatility over 60 trading days |
| `vol_252d` | Issuer's stock: annualized volatility over 252 trading days (one year) |
| `ret_252d` | Issuer's stock: total return over the last year |
| `mom_12_1` | Issuer's stock: return from 12 months ago to 1 month ago (momentum) |
| `beta_252d` | Issuer's stock: sensitivity to the S&P 500 (SPY) over one year |
| `log_market_cap` | log(market value of the issuer's shares, USD) |
| `total_debt` | Issuer's total debt from the latest balance sheet published before the snapshot, USD |
| `leverage` | Market leverage: total debt / (total debt + market cap) |
| `naive_dd` | Distance to default (Bharath-Shumway): how many standard deviations the firm is from default; higher = safer |

### Rates and market backdrop (same for every bond on a date)

| Column | Description |
|---|---|
| `ust_2y_pct` | 2-year Treasury yield, percent |
| `ust_10y_pct` | 10-year Treasury yield, percent |
| `slope_2s10s_bps` | 10-year minus 2-year Treasury yield, basis points (shape of the yield curve) |
| `hy_oas_bps` | Average spread of the US high-yield bond market (ICE BofA index), basis points |
| `bbb_oas_bps` | Average spread of BBB-rated corporate bonds (ICE BofA index), basis points |
| `vix` | VIX: expected volatility of the S&P 500 (market fear gauge) |
| `sofr_pct` | SOFR: the overnight secured funding rate, percent |

**Not allowed as model inputs:** `snapshot_date`, `cusip_id`, `issuer_ticker`, `issuer_name`, `partition`, `spread_bps`, `yield_pct`, `ust_yield_at_maturity_pct`, `price`, `spread_change_next_bps`, `widens_25bp`, `grade`.
